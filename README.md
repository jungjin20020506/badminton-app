# 🏸 셔틀빌리지 (Shuttle Village)

**동물의 숲 감성의 3D 배드민턴 클럽 마을 게임.**
콕스타(COCKSTAR)의 계정·경기방을 그대로 쓰면서, 클럽 운영을 3D 마을로 보여줍니다.

휴대폰 세로 화면 기준으로 만들었고, 설치 없이 브라우저에서 바로 돌아갑니다.

```bash
npm install
npm run dev          # 내 PC에서 실행
npm run dev -- --host  # 같은 와이파이의 휴대폰에서 접속
```

### 🧑‍🎨 내 캐릭터 만들기
머리 10종 · 눈매 6종 · 피부 8톤 · 유니폼 5종 · 액세서리 · 키까지 고르고,

실시간 3D 미리보기로 돌려보면서 꾸밉니다.

### 🏝️ 마을과 경기
- 선수를 넣으면 마을 입구에서 등장 → 대기석으로 걸어가고, 매칭되면 코트로 이동
- **4명이 다 도착하면 경기가 자동으로 시작**되고 셔틀콕이 오갑니다
- 코트는 1~6개까지 조절, 낮/밤이 흐르고 밤에는 가로등이 켜집니다
- 자동매칭은 콕스타의 설계를 계승 — 급수 밸런스 · 대기시간 · 다양성 · 민감도 4단계

### 🎮 계속 하게 만드는 것들
출석 도장판(7일) · 연승 보너스 · 오늘의 추천 파트너(코인 2배) · 일일 퀘스트 ·
셔틀콕 뽑기 · 우편함 · 트로피룸 13종 · 마을 발전도 5단계 · 랭킹 ·
미니게임 「셔틀 리프팅」 · 코인 상점(머리/옷/라켓/마당 꾸미기/코트 바닥)

**마을 발전도가 오르면 마을이 실제로 변합니다** — 축제 깃발 → 벚나무 길 →
하늘의 열기구 → 황금 셔틀콕 기념비. 트로피를 따면 클럽하우스 앞에 진짜로 진열됩니다.

### 📸 인스타그램 스토리 공유
카메라로 각도를 잡고 찰칵 → 9:16 스토리 카드가 만들어집니다.
사진 위에 이름·급수·모임·날짜·오늘 전적만 은은하게 얹는 미니멀 디자인이고,
공유 버튼으로 인스타그램 스토리에 바로 올릴 수 있습니다.

### 🔗 콕스타 연동
콕스타 계정(카카오 / 휴대폰)으로 로그인하면 **콕스타 경기방이 그대로** 보입니다.
입장하면 참가자들이 각자 캐릭터로 마을에 나타나고,
콕스타에서 코트에 선수를 넣으면 여기서 그 선수가 코트로 걸어갑니다.
방 관리자는 셔틀빌리지에서도 경기를 시작·종료할 수 있습니다.

자세한 내용과 배포 전 설정은 [콕스타_연동_가이드.md](콕스타_연동_가이드.md) 참고.

## 기술

- **React 19 + Vite**
- **three.js + @react-three/fiber + drei** — 3D
- **@react-three/postprocessing** — 블룸 / 피사계심도 / 앰비언트 / 색보정
- **zustand** — 게임 상태
- **Firebase (Auth + Firestore)** — 콕스타와 공유
- 텍스처·아이콘·캐릭터 전부 **코드로 생성**합니다. 외부 3D 파일이나 이미지가 없습니다.

```
src/
  game/      게임 규칙 — 상수 · 자동매칭 · 상태 저장소 · 좌표 · 소셜(파트너/우편/트로피)
  three/     3D — 씬 · 마을 · 코트 · 캐릭터 · 액터(이동) · 절차적 텍스처
  ui/        화면 — HUD · 패널 · 캐릭터 제작 · 로그인 · 경기방 · 미니게임 · 스토리 공유
  net/       콕스타 Firebase 연동
tools/       앱 아이콘 생성기 (node tools/make-icons.cjs)
```

## 알아둘 점

- 로그인하지 않으면 데이터가 **그 폰 안에만** 저장됩니다(localStorage).
- 경기방 모드에서는 승패가 아니라 **경과 시간**이 표시됩니다 (콕스타에 승패 개념이 없음).
- 폰이 느리거나 뜨거우면 **⚙️ 설정 → 그래픽 품질 → 가볍게** 로 바꾸세요.
