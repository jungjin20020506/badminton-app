# 🏸 셔틀몬스터 (ShuttleMonster)

**닌텐도 포켓몬스터 감성의 2D 도트 배드민턴 RPG.**

셔틀타운을 직접 걸어 다니고, 주민에게 말을 걸고, 상점 문을 열고 들어가면
화면 색이 통째로 바뀌는 — 그 옛날 게임보이의 느낌 그대로.
콕스타(COCKSTAR)의 계정·경기방을 그대로 물려받아 실제 클럽 운영도 됩니다.

휴대폰 세로 화면 기준으로 만들었고, 설치 없이 브라우저에서 바로 돌아갑니다.

```bash
npm install
npm run dev            # 내 PC에서 실행
npm run dev -- --host  # 같은 와이파이의 휴대폰에서 접속
```

## 🎯 이 게임의 목적지 — 경기방

셔틀몬스터의 첫 목표는 **경기방에 들어가는 것**입니다.
포켓몬처럼 처음부터 혼자 두지 않고, 이야기가 손을 잡고 데려다줍니다.

1. **내 방에서 눈을 뜬다** — 오늘은 셔틀타운에서 맞는 첫날
2. **마을로 나오면 안내원 코코가 달려온다** — 경기방이 뭔지 설명해 줍니다
3. **체육관 문 위에 노란 화살표가 뜬다** — 그대로 따라가면 됩니다
4. **관장 태호가 오늘 열린 경기방을 보여 준다** — 마음에 드는 방을 골라 입장
5. **입장하는 순간 대진표가 펼쳐진다** — 경기 진행 · 경기 예정 · 대기 선수 카드

체육관 **접수 데스크**를 조사해도 언제든 경기방 목록을 열 수 있습니다.

### ⏳ 대기하는 동안은 마을에서 논다

대진표를 닫으면 화면 왼쪽 위에 **경기방 창이 작게 남습니다.**
「대기 12명」 같은 숫자가 아니라 **내가 몇 번째이고 몇 분쯤 남았는지**를 알려 줍니다.

| 표시 | 뜻 |
|---|---|
| ⏳ 대기 3번째 · 약 12분 뒤 | 최근 경기 평균 시간으로 계산한 내 차례 |
| 📋 내 순번 2번째 | 이미 대진표에 이름이 올라감 |
| ⏰ **바로 다음 차례야!** | 노란 테두리 + 진동 알림 |
| 🔥 **N번 코트에서 경기 중!** | 빨간 창이 콩콩 뜁니다 |

작은 창을 누르면 곧바로 대진표로 돌아옵니다.
그 사이에 마을을 돌아다니며 상점을 털든 뽑기를 돌리든 자유입니다 — 순번은 창이 챙겨 줍니다.
**내 차례가 오면 게임이 먼저 "이제 코트로 가"라고 말해 줍니다.**

## 🚫 승패는 기록하지 않습니다

실제 클럽에서 관리자가 매 경기 승패를 일일이 물어보고 누르는 건 불가능합니다.
그래서 셔틀몬스터의 **모든 성장은 「얼마나 뛰었고 누구와 뛰었는가」로만** 이뤄집니다.

| 대신 쌓이는 것 | 어디에 |
|---|---|
| 📖 **선수 도감** | 같은 코트에 서 본 사람을 수집. 못 만난 사람은 실루엣(？？？) |
| 🎖️ **배지 8종** | 경기 수 · 도감 · 연속 출석 · 리프팅으로 획득 |
| ⚔️ **라이벌** | 가장 자주 같은 코트에 선 사람이 자동 지정 |
| 📘 **장(章)** | 경기 수로 열리는 5개 장 — 열릴 때마다 마을이 실제로 변합니다 |
| 📋 **오늘의 기록판** | 최다 출전 · 가장 친해진 사람 · 리프팅 최고 (체육관 전광판에도) |

마을 발전 단계가 오르면 **깃발 → 벚나무 → 분수대**가 실제 타일 위에 하나씩 생깁니다.

## ✨ 포켓몬에서 가져온 것들

- **「!」 발견** — NPC가 보고 있는 방향에 들어서면 느낌표를 띄우고 달려와 말을 겁니다
- **풀숲** — 밟으면 가끔 코인을 줍거나 셔틀콕이 굴러 나옵니다
- **리포트** — 침대에서 "리포트를 쓰고 있습니다…" → "저장했습니다!"
- **지역 이름표** — 문을 지날 때마다 지역명이 스윽 떠올랐다 사라집니다
- **트레이너 카드 · 배지 케이스 · 도감** — 그 화면 구성 그대로
- **잔디가 길 위로 자라나는 경계 처리**와 실내 창문 채광, 화면 가장자리 비네팅

## 🎮 조작 (게임보이 그대로)

| | 조작 |
|---|---|
| **십자키** | 한 칸씩 걷기. 손가락을 올린 채 방향을 바꿔도 이어서 걷습니다 |
| **Ⓐ** | 말 걸기 · 조사하기 · 대화 넘기기 · 선택지 결정 |
| **Ⓑ** | 누른 채 걸으면 **달리기** / 대화·창 닫기 |
| **☰ START** | 메뉴 (경기 · 명단 · 트레이너 카드 · 가방 · 미션 · 우편 · 기록 · 설정) |

키보드도 됩니다 — `방향키/WASD`, `Z·Enter·Space`(Ⓐ), `X·Shift`(Ⓑ), `Esc`(메뉴).

## 🗺️ 셔틀타운

문 앞 매트를 밟으면 화면이 어두워졌다 밝아지면서 안으로 들어가고,
**타일 색과 UI 색이 그 지역 테마로 통째로 갈아입습니다.**

| 장소 | 테마 | 여기서 하는 일 |
|---|---|---|
| 🏠 **내 방** | 나무 | 침대(휴식) · 옷장(꾸미기) · PC(기록·트로피·트레이너 카드) · TV |
| 🏟️ **셔틀 체육관** | 남색 | **관장 태호** 또는 **접수 데스크** → 경기방 목록 · 대진표 · 자동 매칭. 코트 최대 6면이 실제로 깔리고, 경기 중인 선수가 코트 위에 서 있습니다 |
| 🛒 **셔틀마트** | 파랑 | **점원**에게 말 걸기 → 상점 열기 / 옷 갈아입기 |
| 💗 **셔틀센터** | 분홍 | **접수원 하나**에게 말 걸기 → 쉬어가기(출석 도장) / 오늘의 미션 / 우편함 |
| 🎰 **뽑기 코너** | 보라 | 셔틀콕 뽑기 · 리프팅 미니게임 |

광장에는 안내원 코코, 동네 코치, 이웃 주민들이 돌아다니고
**선수 명단에 등록된 사람들이 실제 마을 주민으로 걸어 다닙니다.**
말을 걸면 친밀도와 오늘 출전 수를 보여 주고, 잠깐 쉬라고 하거나 대진표로 넘어갈 수 있습니다.

시간대에 따라 마을 색이 아침·낮·노을·밤으로 물듭니다.

## 🏸 배드민턴 기능 (그대로 유지)

- 급수 7단계(S~N조) 기반 **자동 매칭** — 민감도 4단계
- 코트 1~6면 · 경기 진행/종료 (점수·승패는 기록하지 않음)
- 육성 — 레벨·경험치·스탯 5종(스매시/기술/스피드/체력/센스)
- 상점 — 머리 18종, 눈매 6종, 상의 11종, 하의 5종, 신발 4종, 액세서리 10종, 라켓 8종
- 출석 도장판 · 일일 미션 · 트로피 · 우편함 · 뽑기 · 리프팅 미니게임
- 인스타그램 스토리 공유 (도트 화면 그대로 9:16 카드로)
- **콕스타 연동** — 같은 계정으로 로그인하면 콕스타 경기방이 그대로 보이고,
  콕스타에서 선수를 코트에 넣으면 체육관 코트에도 그 선수가 섭니다

## 🛠 기술

- **React 19 + Vite + three.js (react-three-fiber)** — 진짜 HD-2D
- **zustand** — 게임 상태
- **Firebase (Auth + Firestore)** — 콕스타 계정·경기방 공유
- **그래픽은 전부 코드로 생성** — 잔디 한 포기, 지붕 기와 한 장, 캐릭터 도트까지
  `fillRect` 로 찍어 만듭니다. 외부 이미지·스프라이트 파일이 하나도 없습니다
- **32px 고해상도 타일 · 32x48 캐릭터** — 재질마다 명암 5단계, 접지 그림자(AO),
  건물은 박공지붕·처마 그늘·측면 벽·기초 석재까지 그려 **2D인데 입체로** 보입니다
- **진짜 HD-2D** — 도트 스프라이트를 **실제 3D 공간에 세웁니다**(옥토패스 트래블러 방식).
  기울어진 원근 카메라로 내려다보고, 스프라이트가 방향광을 받아 바닥에 제 모양대로
  그림자를 드리우고, 블룸과 비네팅이 화면을 묶습니다. 가로막는 소품은 비쳐 보입니다.
  설정에서 그래픽 '낮음'을 고르면 그림자·후처리가 꺼집니다
- 게임 로직(이동·충돌·대화·경기)은 전부 2D 타일 엔진 그대로입니다. 3D는 **그리기 전용**입니다
- 한글 픽셀 폰트는 **갈무리(Galmuri)** 를 CDN 으로 불러옵니다 (실패해도 시스템 폰트로 대체)

```
src/
  pixel/       2D 엔진
    palette.js   지역 테마(타일 색 + UI 색). 맵이 바뀌면 CSS 변수까지 갈아탄다
    tileset.js   32x32 타일과 나무·건물·코트 오브젝트를 명암 5단계로 굽는다
    sprites.js   look 데이터 → 4방향 x 4프레임 32x48 캐릭터 시트 (외곽선·접지 그림자)
    maps.js      마을/마트/센터/체육관/집/뽑기코너 지도와 충돌·문·NPC 배치
    engine.js    칸 단위 이동 · 충돌 · 문 통과 · Ⓐ 조사 · 화면 그리기
    talk.js      대화 진행기 (타자기 · 선택지)
    scripts.js   NPC·간판·가구 대사집
    story.js     오프닝 이야기 — 어디서 누가 말을 걸고, 어디로 안내할지
  game/        게임 규칙 — 급수·자동매칭·상태 저장소·소셜
  hd2d/        HD-2D 렌더러 — 도트 캔버스를 3D 텍스처로 올리고 씬을 구성
  ui/          화면 — 필드/대화창/십자키/메뉴/패널
  net/         콕스타 연동
```

### 개발 중 화면 확인

브라우저 콘솔에서:

```js
__svEngine.tick(0.2)                 // 한 프레임 굴리고 다시 그리기
__svEngine.loadMap('gym', 10, 24, 1) // 원하는 지도로 바로 이동
__svWorld                            // 지금 월드 상태
__svStore.getState()                 // 게임 상태
```

`vite.config.js` 의 `/__save` 엔드포인트로 캔버스를 `.snapshots/` 에 PNG 로 떨굴 수 있습니다.
